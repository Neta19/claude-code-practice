# Clinic Dashboard Project

An interactive RTL Hebrew dashboard (`dashboard.html`) summarizing a year of
activity for an emotional-therapy clinic — KPIs, charts, and a monthly table.
See `spec.md` for the full specification and `README.md` for project docs.

## Workflow rules (apply automatically, no need to ask)

- **Always commit and push.** After making a change to this project, commit
  it with a clear message and push to `origin/master`
  (github.com/Neta19/claude-code-practice) without stopping to ask for
  confirmation first.
- **Always update documentation alongside code changes.** Before committing,
  update `README.md` to reflect what changed (new sections, features,
  metrics, etc.), and update `spec.md` if the change alters the spec itself.
  Documentation changes go in the same commit as the code change.
- Keep commit messages focused on *why* the change was made, not just what.
