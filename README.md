# דשבורד קליניקה

דשבורד אינטראקטיבי (RTL, בעברית) המסכם שנה של פעילות בקליניקה לטיפול רגשי:
טיפולים, לקוחות (חדשים מול ממשיכים), ביטולים והכנסות.

🔗 **מתארח כאן:** [neta19.github.io/claude-code-practice](https://neta19.github.io/claude-code-practice/)

- **הקובץ הראשי:** [`dashboard.html`](dashboard.html) — עמוד HTML עצמאי (ללא תלות בשרת), ניתן לפתיחה ישירות בדפדפן.
- **המפרט המלא:** [`spec.md`](spec.md)
- **טבלת הנתונים כ-CSV:** [`טבלה_חודשית.csv`](טבלה_חודשית.csv) — אותם נתונים חודשיים שמוצגים בטבלה שבדשבורד, לפתיחה ב-Excel/Sheets.

## מה יש בדשבורד

- 5 כרטיסי KPI: סך טיפולים, סך הכנסות, לקוחות חדשים, ביטולים, ממוצע טיפולים לחודש.
- 4 גרפים: טיפולים לפי חודש, מגמת הכנסה חודשית, לקוחות חדשים מול ממשיכים, ביטולים לפי חודש.
- טבלה חודשית מרכזת עם כל הנתונים, כולל כפתור "הורד כ-CSV" שמייצא אותה ישירות מהדשבורד.
- בורר תצוגה: "כל השנה" (סיכום שנתי) או חודש ספציפי (מדגיש את החודש בכל הגרפים והטבלה).
- תמיכה במסך מובייל ובמצב כהה (dark mode).

## נתונים

הנתונים בדשבורד הם נתוני הדגמה פיקטיביים (12 חודשים, אוקטובר 2025–ספטמבר 2026).
רק הקלט הגולמי לכל חודש מוזן בקוד (לקוחות חדשים/ממשיכים, טיפולים שבוצעו, ביטולים) —
כל שאר הערכים (סה"כ לקוחות, הכנסה, ממוצעים וסיכומים שנתיים) מחושבים אוטומטית
מתוך הנתונים הגולמיים ב-JavaScript (`dashboard.html`), כולל הנוסחה
הכנסה חודשית = מספר הטיפולים שבוצעו × 350 ₪.

## עדכון הנתונים

כדי לעדכן את הנתונים, ערכו את מערך `RAW` בתוך `dashboard.html` (חיפוש לפי
`const RAW = [`) — כל שאר הדשבורד (KPIs, גרפים, טבלה) יתעדכן אוטומטית.
אם משנים את הנתונים, כדאי לעדכן בהתאם גם את [`טבלה_חודשית.csv`](טבלה_חודשית.csv) כדי שיישאר תואם.
